# Playtest Kit UI

Shared UI patterns and components for the weekly collective intelligence playtests, built on [Kumo](https://kumo-ui.com) and React.

## Adding a component

1. Create `src/<Name>/<Name>.tsx` and export it from `src/index.ts`.
2. Add `src/<Name>/<Name>.stories.tsx` next to it.
3. Run `pnpm --filter @playtest-kit/ui storybook`.
